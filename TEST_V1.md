# Teste rápido — V1 imersiva

1. Abra o app pelo GitHub Pages ou rode `python -m http.server 8000` e abra `http://localhost:8000`.
2. Crie um jogador e escolha **Titã da Preguiça** como inimigo.
3. Ligue `♪ Trilha` e teste o **◎ Foco**: a música deve mudar.
4. Conclua hábitos: som de missão, dano no chefe e level up.
5. Para testar a virada do dia, no console: altere `day` no save `sistema-disciplina-v2` para uma data antiga e recarregue.
   Com sequência maior que 0 e hábitos pendentes, aparecem a **Penalidade** e o **Ladrão de Sequência**.
6. Para testar o dia 21: deixe um hábito com `h: 20` no save, recarregue e conclua-o.
